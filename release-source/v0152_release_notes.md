V0.1.52 - 어비스 결과 다시 하기 인식 수정

사용자 캡처에서 어비스 결과 화면의 나가기 / 다시 하기 / 다른 던전 가기 버튼이 모두 보이는데도,
세 문구를 동시에 OCR로 확인해야 하는 기존 조건 때문에 정지하던 문제를 수정했습니다.

- 800×1000 게임창에서만 동작
- 어비스 결과의 아래 중앙 안전영역 x=280~520, y=900~995 안에서 "다시 하기"만 확인
- "다시 하기"가 2프레임 연속 같은 위치에서 확인된 경우에만 OCR 중심점을 클릭
- 나가기 / 다른 던전 가기는 클릭 후보로 사용하지 않음
- 고정 좌표 무조건 클릭도 사용하지 않음
- 다시 하기 후 결과 화면 이탈 확인도 같은 안전영역만 사용
- 일반 던전, 페카 심층, 어비스 전투/클리어, 낚시, F10, UI, 이미지 미리보기 등 다른 기능은 변경하지 않음
