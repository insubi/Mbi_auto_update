# Mabi Auto V0.1.73

이번 버전은 어비스 전리품 카운팅과 네트워크 재접속을 함께 수정합니다.

## 전리품 카운팅
- 기존 OCR 단독 판정 대신 사용자가 제공한 11개 전리품 아이콘을 이미지 템플릿으로 등록합니다.
- 실제 결과 화면에서 같은 아이템 이미지가 2프레임 연속 확인되어야 판당 +1 카운트합니다.
- 이미지 매칭이 잡히지 않을 때만 기존 OCR을 보조 수단으로 사용합니다.
- 같은 결과 화면은 기존 `_abyssLootCountedForCurrentResult` 보호로 한 번만 기록합니다.
- `모르 코르셰어 코트 (남성용)`은 표시/카운팅 이름을 기존대로 `모르 코르셰어 코트`로 유지합니다.
- Telegram `/item`, `/itemreset`과 기존 누적 저장 형식은 유지합니다.

추적 대상:
- 허상의 마력석 / 포식의 마력석 / 심해의 마력석
- 룬새김 장식(★10) / 룬새김 장식(★10)+
- 룬결속 장식(★10) / 룬결속 장식(★10)+
- 모르 코르셰어 코트 / 글러브 / 부츠 / 트리코른

## 네트워크 재접속
- 어비스 실행 중 `네트워크 상태가 불안정합니다`와 `다시 시도하기`를 함께 2프레임 확인합니다.
- 확인되면 마우스 대신 Space를 1회 입력합니다.
- 같은 팝업이 5초 이상 유지될 때만 Space를 한 번 더 허용합니다.
- 팝업이 3프레임 연속 사라진 것을 확인하면 기존 판 상태/10분 타이머를 초기화하고 어비스 처음부터 재시작합니다.
- `시작 화면으로`는 누르지 않습니다.
- 45초 안에 팝업 종료가 확인되지 않으면 안전 정지합니다.

V0.1.72의 클리어 타이틀 2프레임 안전 fallback, 사망 로직 제거, 판당 10분 제한은 그대로 유지합니다.
