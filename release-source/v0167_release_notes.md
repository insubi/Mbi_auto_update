# Mabi Auto V0.1.67

V0.1.66 기준으로 **사망 후 5분 대기를 비차단 방식으로 수정**한 버전입니다.

## 변경 사항

- 기존 문제: 사망 2/2 확인 후 `Task.Delay(5분)`이 어비스 진행 루프 자체를 멈춰, 대기 중 파티가 던전을 클리어해도 `화면을 터치해 주세요` 처리가 실행되지 않았습니다.
- 사망 2/2 확인 시 이제 **5분 퇴장 타이머만 예약**하고 화면 감시는 계속합니다.
- 5분 대기 중 `던전 클리어 / 화면을 터치해 주세요`가 확인되면:
  - 예약된 사망 퇴장을 즉시 취소
  - 기존 클리어 화면 처리에 우선권을 넘김
  - 이후 결과 화면 → 다시 하기 → 재입장 흐름을 그대로 진행
- 대기 중 결과/다시 하기 화면으로 이미 전환된 경우에도 퇴장 예약을 취소합니다.
- 5분이 실제로 만료되면 새 화면 2장으로 사망 상태를 재확인합니다.
  - 사망 2/2 유지: 기존 안전 퇴장
  - 사망 해제 또는 클리어/결과 전환: 퇴장 취소 후 현재 진행 계속
- F10 정지는 기존과 동일하게 언제든 동작합니다.

## 유지 사항

- V0.1.66 사망 시각 보조 인식 유지
- V0.1.66 장면 넘기기 인식 및 사망 우선순위 유지
- V0.1.64 클리어 후보 로그 단순화 유지
- 텔레그램 명령어/약어 변경 없음
- 공용 입력 잠금 유지

- 회복 물약 ESC 처리 유지
- 일반 던전, 페카 심층, 낚시, UI 변경 없음
