# Mabi Auto V0.1.68

V0.1.67 기준으로 **어비스 전리품 카운팅과 텔레그램 조회/초기화 기능**을 추가한 버전입니다.

## 전리품 카운팅

실제 어비스 결과 화면의 `다시 하기`가 2회 연속 확인된 뒤, 클릭 직전에 전리품 목록을 OCR로 확인합니다. 같은 결과 화면은 한 판에 한 번만 집계합니다.

추적 아이템 11종:
- 허상의 마력석
- 포식의 마력석
- 심해의 마력석
- 룬새김 장식(★10)
- 룬새김 장식(★10)+
- 룬결속 장식(★10)
- 룬결속 장식(★10)+
- 모르 코르셰어 코트
- 모르 코르셰어 글러브
- 모르 코르셰어 부츠
- 모르 코르셰어 트리코른

각 아이템은 한 판에서 확인되면 +1, 없으면 +0입니다. 룬 장식의 일반/플러스 버전은 OCR의 `+` 표기와 텍스트 색상 신호를 함께 사용해 구분합니다.

## 텔레그램

- `/stone`
  - 이번 실행 / 오늘 / 누적 수량을 한 번에 표시
  - 마력석 / 장식 / 모르 코르셰어로 나눠 표시
- `/stonereset`
  - 확인 단계 없이 **누적 수량만 즉시 0으로 초기화**
  - 이번 실행/오늘 수량은 유지

## 저장

- 누적/오늘 기록은 Windows 사용자 LocalAppData의 MabiAuto 폴더에 저장되어 프로그램 재실행 및 업데이트 후에도 유지됩니다.
- 날짜가 바뀌면 오늘 수량만 자동으로 0부터 다시 시작합니다.
- 이번 실행 수량은 프로그램을 새로 실행하면 0부터 시작합니다.
