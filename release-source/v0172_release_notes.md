# Mabi Auto V0.1.72

- 어비스 클리어 화면에서 `던전 클리어!` 타이틀은 안정적으로 잡히지만 `화면을 터치해 주세요` 템플릿 점수가 0.68 미만으로 흔들릴 때 클리어를 놓치던 문제를 보완합니다.
- 기존의 가장 안전한 1순위 조건인 **클리어 타이틀 + 터치 문구 동시 인식**은 그대로 유지합니다.
- 800×1000 클라이언트에서 클리어 타이틀 점수 0.68 이상이 **2프레임 연속** 확인되면, 기존 안전 터치 위치 중심 (400,945)을 1회 사용합니다.
- 터치 템플릿의 전역 임계값 0.68은 낮추지 않습니다.
- 10분 타임아웃 경계에서 클리어 타이틀 후보가 보이면 해당 프레임의 퇴장 입력을 보류하고, 2/2 확정 시 강제 퇴장을 취소하고 정상 클리어 처리로 전환합니다.
- Smart Recovery에서도 다시 터치 템플릿을 재요구하지 않고 이미 확정된 터치 위치/안전 fallback 위치를 그대로 사용합니다.
- V0.1.71의 사망 감지/카운트/5분 퇴장 제거와 판당 10분 제한은 그대로 유지합니다.
- 전리품 OCR/카운팅, Telegram /item /itemreset, 결과 화면, 다시 하기 흐름은 변경하지 않습니다.
