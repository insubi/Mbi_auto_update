# Mabi Auto V0.1.60

V0.1.59를 기준으로 회복 물약 부족 팝업 처리와 어비스 결과 화면 판별만 보강한 버전입니다.

## 변경 사항

- 회복 물약 부족 팝업
  - 일반 던전과 어비스 모두 감시합니다.
  - 팝업을 2회 확인한 뒤 마우스로 닫기/구매 버튼을 클릭하지 않고 ESC를 정확히 1회 입력합니다.
  - ESC 입력 후 팝업이 2프레임 연속 사라진 것을 확인해야 원래 진행으로 복귀합니다.
  - 닫힘을 확인하지 못하면 추가 입력이나 구매 클릭 없이 안전 정지합니다.

- 어비스 결과 화면 다중 신호 판별
  - `다시 하기` OCR 단독 검출만으로는 결과 화면으로 인정하지 않습니다.
  - 기존 실제 결과 화면의 나가기/다시 하기/다른 던전 가기 3개 버튼 영역이 모두 녹색 결과 버튼 형태로 확인되어야 합니다.
  - OCR은 보조 신호로만 사용합니다.
  - 기존과 동일하게 결과 화면이 2프레임 연속 확인되어야 `다시 하기` 클릭이 허용됩니다.

## 유지 사항

- V0.1.59 어비스 상태머신과 클릭 순서 유지
- 일반 던전은 현재 위치 시작 방식 유지
- 페카 심층 이동 로직과 일반 던전 로직 분리 유지
- F10 정지, 낚시, UI, 기존 좌표/결과 버튼 녹색 임계값은 변경하지 않음
