# Mabi Auto V0.1.64

V0.1.63을 기준으로 **어비스 사망 후 퇴장 지연**과 **클리어 후보 로그 단순화**만 적용한 버전입니다.

## 변경 사항

- `행동불능 + 여기서 부활`이 별도 프레임에서 2/2 확인되면 즉시 퇴장하지 않습니다.
- 사망 2/2 확인 후 **정확히 5분 대기**한 다음 기존 던전 퇴장 절차를 시작합니다.
- 5분 대기 중에는 부활 버튼이나 구매 관련 입력을 하지 않습니다.
- F10 정지는 기존과 동일하게 5분 대기 중에도 즉시 취소할 수 있습니다.
- 일반 전투 중 반복되던 `클리어 후보 점수` 저점수 로그를 숨깁니다.
- 클리어 인식 판정 자체는 변경하지 않고, title 또는 touch 점수가 **0.65 이상인 강한 후보**일 때만 간단한 후보 로그를 남깁니다.

## 유지 사항

- 텔레그램 명령어/약어 변경 없음
- V0.1.63 공용 입력 잠금 유지
- V0.1.62 사망 판정 2프레임 확인 및 부활/구매 금지 유지
- V0.1.62 장면 넘기기 2프레임 확인 유지
- V0.1.61 클리어 → 결과 → 다시 하기 상태머신 유지
- 회복 물약 ESC 처리 유지
- 일반 던전, 페카 심층, 낚시, UI 변경 없음
