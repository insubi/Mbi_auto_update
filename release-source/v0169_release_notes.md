# Mabi Auto V0.1.69

V0.1.68 기준으로 텔레그램 전리품 명령어 이름만 변경한 버전입니다.

## 변경 사항

- 전리품 조회: `/stone` → `/item`
- 누적 초기화: `/stonereset` → `/itemreset`
- 전리품 카운팅/저장 방식 변경 없음

## 유지 사항

- 어비스 전리품 11종 카운팅 유지
- 이번 실행 / 오늘 / 누적 통계 유지
- `/itemreset`은 확인 단계 없이 누적 수량만 즉시 0으로 초기화
- V0.1.67 비차단 사망 5분 타이머 유지
- 기존 어비스 결과/다시 하기 상태머신 유지
- 일반 던전, 페카 심층, 낚시, F10, UI 변경 없음
