V0.1.58 - 실제 어비스 화면 오프라인 회귀 테스트 추가

이번 버전은 자동화 동작을 변경하지 않습니다.
V0.1.57을 안정 기준으로 두고 실제 사용자 캡처를 이용한 CI 테스트 환경만 추가했습니다.

자동 검사:
- 실제 어비스 결과 화면이 production 결과 판별기로 인식되는지
- 실제 S 던전 클리어 / 화면을 터치해 주세요 화면을 결과 화면으로 오인하지 않는지
- 799×1000, 800×999 프레임에서도 V0.1.55 비례 ROI 결과 판별이 유지되는지
- 실제 클리어 화면에서 production abyss_dungeon_clear_visual 판별이 동작하는지
- 실제 클리어 화면에서 production abyss_touch_screen 판별이 동작하는지
- 실제 결과 화면을 클리어+터치 화면으로 동시에 오인하지 않는지

안전 원칙:
- 테스트는 빌드된 실제 FishingAutomation.dll의 production 코드를 reflection으로 호출
- 판별 코드를 테스트 프로젝트에 복사하지 않음
- 클릭/좌표/ROI/임계값/상태전환/게임 로직 변경 없음
- V0.1.56 진단 기능 유지
- V0.1.57 자동업데이트 복구 구조 유지
- 런타임 소스는 버전 메타데이터 2개 파일 외 변경 금지
