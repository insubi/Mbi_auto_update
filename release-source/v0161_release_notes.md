# Mabi Auto V0.1.61

V0.1.60 정식 릴리스를 기준으로, 오늘 확인된 어비스 전투 중 결과 화면 오인과 회복 물약 팝업 닫기 문제를 함께 수정한 버전입니다.

## 수정 1: 전투 중 결과 화면으로 잘못 넘어가는 문제

- 정상 5단계 `CombatClearWait`에서 결과 화면을 먼저 한 번 검사하고 바로 `ResultConfirmed`로 넘어가던 fast-path를 제거합니다.
- 상태머신에서도 `CombatClearWait -> ResultConfirmed` 직접 전이를 금지합니다.
- 정상 진행은 `CombatClearWait -> ClearConfirmed -> TouchReady -> TouchClicked -> ResultConfirmed` 순서를 사용합니다.
- 클리어 화면을 터치한 뒤 실제 결과 화면은 같은 위치의 결과 판정이 2프레임 연속 확인되어야 확정합니다.
- 전투 중 하단 UI가 결과 버튼 색상 조건을 우연히 만족하더라도 한 프레임 오검출만으로 6단계에 진입하지 않습니다.

## 수정 2: 실제 결과 화면 인식 범위

- V0.1.60의 결과 화면비 상한 0.86 때문에 약 815×920 같은 실제 캡처가 거부될 수 있어 상한을 0.92로 조정합니다.
- 나가기 / 다시 하기 / 다른 던전 가기 3개 녹색 버튼 영역 판정과 가운데 다시 하기만 클릭하는 규칙은 유지합니다.

## 수정 3: 회복 물약 부족 팝업 닫기

- 기존 닫기 템플릿 검색 범위를 화면 하단 절반으로 넓히고 스케일 범위를 확대합니다.
- 큰 제목 `회복 물약이 부족합니다` OCR을 독립 감시 신호로 추가합니다.
- 제목 또는 닫기 템플릿이 확인되면 마우스 구매/닫기 좌표를 클릭하지 않고 ESC 1회를 보냅니다.
- ESC 후 팝업이 2프레임 연속 사라져야 원래 진행으로 복귀합니다.
- 어비스 자동복구에 남아 있던 예전 `popup_close` 마우스 클릭 경로도 제거하고 같은 ESC 처리로 통일합니다.
- ESC로 닫히지 않으면 구매 버튼이나 임의 좌표를 클릭하지 않고 복구 실패로 처리합니다.

## 유지 사항

- 일반 던전 현재 위치 시작 방식 유지
- 페카 심층 이동 로직 분리 유지
- 낚시, F10 정지, 기존 UI 유지
- 어비스 결과 화면에서 가운데 다시 하기만 클릭하는 안전 규칙 유지
