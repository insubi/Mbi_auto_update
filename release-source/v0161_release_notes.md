# Mabi Auto V0.1.61

V0.1.60 정식 릴리스를 기준으로 어비스에서 확인된 두 가지 실사용 오류만 수정한 버전입니다.

## 수정 1: 어비스 결과 화면에서 '다시 하기' 미클릭

- V0.1.60은 결과 화면 판정 전에 캡처 화면비를 0.74~0.86으로 제한했습니다.
- 실제 세로형 캡처 중 약 815×920처럼 화면비가 약 0.886인 경우, 하단에 '다시 하기'가 실제로 보여도 결과 화면을 즉시 거부할 수 있었습니다.
- 허용 상한을 0.92로 조정합니다.
- 나가기 / 다시 하기 / 다른 던전 가기 3개 녹색 버튼 영역 판정, 2프레임 연속 확인, 가운데 다시 하기만 클릭하는 안전 규칙은 그대로 유지합니다.

## 수정 2: 회복 물약 부족 팝업에서 ESC 미입력

- V0.1.60의 'ESC 닫기' 템플릿 검색 영역이 하단 y=800~990으로 너무 좁아 실제 팝업의 'ESC 닫기'가 더 위에 나타나면 감지하지 못할 수 있었습니다.
- 검색 영역을 화면 하단 절반으로 넓히고 템플릿 스케일 범위를 확대합니다.
- 큰 제목 '회복 물약이 부족합니다' OCR을 독립적인 보조 감시 신호로 추가합니다.
- 제목 또는 'ESC 닫기'가 확인되면 V0.1.60의 기존 안전 처리대로 ESC를 정확히 1회 입력하고, 팝업이 2프레임 연속 사라졌을 때만 원래 진행으로 복귀합니다.
- 거래소 구매 버튼은 클릭하지 않습니다.

## 유지 사항

- V0.1.60 회복 물약 ESC 입력/닫힘 검증 로직 유지
- 어비스 상태머신 및 전투/클리어/재입장 순서 유지
- 일반 던전 현재 위치 시작, 페카 심층 분리, 낚시, F10, UI는 변경하지 않음
