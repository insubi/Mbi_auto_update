V0.1.56 - 진단 기능 보강 (동작 로직 변경 없음)

V0.1.55를 안정 기준판으로 유지하면서 문제 발생 시 원인을 빠르게 확인하기 위한 진단 기능만 추가했습니다.

추가된 진단:
- 현재 어비스 단계와 직전→현재 상태 전환 로그
- 실제 캡처 frame 크기
- 마지막 detector ID / Found 여부 / Score / Bounds
- 마지막 OCR 문자열
- 최근 어비스 클릭 이유와 좌표
- 최근 5개 샘플 프레임을 메모리에 보관
- 어비스 실패/타임아웃 발생 시에만 debug 폴더에 최근 프레임과 진단 TXT 저장
- 어비스 다시 하기 오류 메시지에 진단 요약 포함

안전 원칙:
- 클릭 좌표 변경 없음
- detector 임계값/ROI/판정식 변경 없음
- 어비스 상태 전환 조건 변경 없음
- V0.1.55 결과창 비례 ROI + OCR/초록 버튼 fallback 그대로 유지
- V0.1.54 클리어→결과 화면 확정 로직 그대로 유지
- 일반 던전 / 페카 심층 / 낚시 / F10 / 기존 UI 변경 없음
- 정상 판에서는 진단 이미지를 디스크에 저장하지 않음
