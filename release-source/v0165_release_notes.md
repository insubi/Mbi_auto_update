# Mabi Auto V0.1.65

V0.1.64를 기준으로 사용자가 제공한 실제 어비스 녹화 영상을 분석해 **사망 감지**와 **장면 넘기기 감지**만 보강한 버전입니다.

## 변경 사항

- 실제 사망 화면에서 기존 OCR이 `행동불능` / `여기서 부활`을 놓치던 문제를 수정했습니다.
- 어비스 사망 감지는 영상에서 확인된 고정 UI 특성을 사용합니다.
  - 중앙의 빨간 `행동불능` 영역
  - 하단의 주황색 `여기서 부활` 영역
  - 두 신호를 동시에 확인하고 별도 프레임에서 2/2 확인해야 사망으로 확정합니다.
- 사망 2/2 확정 후 기존 요청대로 **5분 대기**합니다.
- 5분이 지난 뒤에도 사망 상태를 새 프레임 2장으로 다시 확인합니다.
  - 계속 사망 상태면 기존 안전 퇴장 절차 진행
  - 부활했거나 결과/다른 화면으로 전환됐으면 **퇴장을 취소하고 현재 진행을 계속**합니다.
- 어비스 `장면 넘기기`는 기존 OCR/구형 템플릿 대신 실제 영상에서 확인한 버튼의 긴 흰색 둥근 테두리 형태를 사용합니다.
- 장면 넘기기는 기존과 동일하게 **2프레임 연속 확인 후 클릭**합니다.
- 일반 전투 우상단 Home/End/ESC HUD는 장면 넘기기 신호로 사용하지 않습니다.

## 유지 사항

- V0.1.64 클리어 후보 로그 단순화 유지
- 텔레그램 명령어/약어 변경 없음
- V0.1.63 공용 입력 잠금 유지
- 부활 버튼/깃털/구매 관련 입력 없음
- V0.1.61 클리어 → 결과 → 다시 하기 상태머신 유지
- 회복 물약 ESC 처리 유지
- 일반 던전, 페카 심층, 낚시, F10, UI 변경 없음
- 사용자가 직접 마우스를 움직여 발생한 다시 하기 커서 검증 실패와 관련된 입력 검증 기준은 변경하지 않았습니다.
