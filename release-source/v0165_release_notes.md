# Mabi Auto V0.1.65

V0.1.64 녹화 영상을 기준으로 **어비스 사망 인식**, **사망 5분 후 재판별**, **장면 넘기기 오인식 차단**만 보강한 버전입니다.

## 변경 사항

- 사망 판정은 기존 OCR을 유지하면서 실제 800×1000 사망 화면의 고정 UI 색상 특징을 보조 신호로 사용합니다.
  - 중앙 상단의 빨간 `행동불능`
  - 하단의 주황색 `여기서 부활` 버튼
- 두 신호가 별도 프레임에서 2/2 확인되어야 사망으로 확정하는 기존 안전 규칙은 유지합니다.
- 사망 확정 후 5분 대기는 그대로 유지합니다.
- **5분이 끝난 뒤 바로 퇴장하지 않고 현재 화면을 다시 확인합니다.**
  - 여전히 사망 화면이면 기존 퇴장 절차 실행
  - 클리어/결과/사망 해제 상태면 퇴장을 취소하고 현재 단계의 정상 진행으로 복귀
- `장면 넘기기`는 OCR 단독 허용을 제거하고 **기존 이미지 템플릿 전용**으로 변경했습니다.
- 장면 넘기기 ROI를 우상단 실제 버튼 영역으로 축소하고 임계값을 강화했습니다.
- 장면 넘기기 1차/2차 확인 중 사망 화면이 확인되면 클릭하지 않습니다.

## 유지 사항

- V0.1.64 낮은 클리어 후보 로그 단순화 유지
- 텔레그램 명령어/약어 변경 없음
- V0.1.63 공용 입력 잠금 유지
- 부활 버튼/깃털/구매 경로 사용 안 함
- V0.1.61 클리어 → 결과 → 다시 하기 상태머신 변경 없음
- 회복 물약 ESC 처리 유지
- 일반 던전, 페카 심층, 낚시, F10, UI 변경 없음
