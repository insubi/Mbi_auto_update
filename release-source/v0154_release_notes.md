V0.1.54 - 어비스 클리어 → 결과 화면 전환 수정

사용자 캡처에서 아직 "S 던전 클리어! / 화면을 터치해 주세요" 화면인데도
다음 단계인 "결과 화면 다시 하기" 대기로 넘어가 120초 후 정지하던 문제를 수정했습니다.

원인:
- 터치 문구를 다시 찾는 중 클리어 템플릿이 3프레임 연속 미검출되면
  실제 화면 전환 여부와 관계없이 5단계를 성공 처리하던 조기 완료 조건.

수정:
- 클리어/터치 템플릿 몇 프레임 미검출만으로 단계 완료하지 않음
- 클리어+터치 동시 확인 시 이미 검출된 터치 위치를 버리지 않고 즉시 사용
- 터치 문구가 흔들릴 경우 800×1000 클리어 화면에서 안전 터치 위치 (400,945) fallback 사용
- 터치 후 실제 어비스 결과 화면이 확인될 때까지 5단계를 끝내지 않음
- 결과 화면 확인 후에만 6단계 "다시 하기"로 진행
- 결과 화면이 30초 안에 확인되지 않으면 다음 단계로 잘못 넘어가지 않고 안전 정지
- 일반 던전, 페카 심층, 낚시, F10, UI, 어비스 미리보기, V0.1.53 다시 하기 OCR/초록 버튼 fallback은 변경하지 않음
