# Mabi Auto V0.1.63

V0.1.62를 기준으로 **던전/어비스 매크로 내부 입력 잠금**만 추가한 안정성 버전입니다.

## 변경 사항

- 던전/어비스 Interception 입력에 공용 입력 잠금을 추가했습니다.
- 매크로가 마우스 클릭과 키보드 입력을 동시에 보내려는 상황이 생겨도 **한 입력이 끝난 뒤 다음 입력이 실행**됩니다.
- 마우스와 키보드가 **같은 잠금**을 사용합니다.
- 이 잠금은 사용자의 실제 키보드/마우스를 막는 기능이 아닙니다. 매크로가 자체적으로 발생시키는 입력만 직렬화합니다.
- 기존 클릭 좌표, 키 입력값, 클릭 후 대기시간, OCR/이미지 판정 조건은 변경하지 않았습니다.
- 실행 로그의 입력 모드에 `input-locked`가 표시되어 적용 여부를 확인할 수 있습니다.

## 유지 사항

- V0.1.62 어비스 사망 시 부활 없이 퇴장→재시작 유지
- V0.1.62 장면 넘기기 2프레임 확인 유지
- V0.1.61 클리어→결과→다시 하기 상태머신 유지
- 회복 물약 ESC 처리 변경 없음
- 일반 던전, 페카 심층, 낚시, F10, UI 변경 없음
