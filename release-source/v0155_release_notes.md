# Mabi Auto V0.1.55

- 어비스 결과 대기 중 클리어 연출이 남아 있으면 제목과 터치 문구를 2회 확인한 뒤 문구 위치를 클릭합니다.
- 실제 결과 화면을 확인한 후 아래 중앙 ‘다시 하기’를 2회 확인하여 재입장합니다.
- 클리어 제목과 터치 문구에 제한 영역 한국어 OCR을 보완하고, 클리어 연출을 결과 버튼으로 오인하지 않도록 우선 구분합니다.
- V0.1.54 기준 낚시, 일반 던전, 최초 입장, 심층 이동, F10, 로그, UI 및 어비스 미리보기는 유지합니다.
- Windows 빌드 및 모의 상태 전환 회귀 검증을 수행합니다. 실제 게임 화면에서의 동작은 사용자 환경에서 확인이 필요합니다.
