V0.1.55 - 어비스 결과 버튼 크기/색 판별 안정화

사용자 결과 화면 캡처의 실제 픽셀을 분석한 결과,
세 초록 버튼 위치는 정상이고 초록 비율도 각각 약 48~52%로 충분했습니다.

남은 취약점:
- 기존 코드는 내부 캡처가 정확히 800×1000일 때만 OCR/시각 fallback을 허용
- 799×1000, 800×999처럼 1픽셀만 달라도 결과 화면 판별을 전부 거부

수정:
- 정확 800×1000 일치 조건 제거
- 실제 캡처 크기에 맞춰 결과 버튼 ROI를 800×1000 기준에서 비례 변환
- 안전한 4:5 근처 화면비(0.74~0.86)에서만 동작
- 초록색뿐 아니라 게임의 청록 계열 버튼도 허용하도록 색 판별 완화
- 세 버튼 영역 모두 최소 18% 이상 녹색/청록 채움일 때만 결과 화면 인정
- 2프레임 연속 확인 후 가운데 다시 하기 영역만 클릭
- 나가기/다른 던전 가기는 클릭 후보가 아님
- 실패 시 Telegram 오류에 실제 frame 크기와 exit/retry/other 초록 비율 진단값 표시
- V0.1.54 클리어→결과 화면 전환 수정, 일반 던전, 페카 심층, 낚시, F10, UI/미리보기는 변경하지 않음
