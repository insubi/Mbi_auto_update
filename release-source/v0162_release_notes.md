# Mabi Auto V0.1.62

V0.1.61을 기준으로 **어비스 사망 처리**와 **장면 넘기기 인식**만 보강한 버전입니다.

## 변경 사항

- 어비스 사망 처리
  - `행동불능`과 `여기서 부활`이 두 프레임 연속 확인될 때만 사망으로 확정합니다.
  - **부활 버튼은 누르지 않습니다.**
  - 빨간 깃털/구매 경로도 사용하지 않습니다.
  - 기존 어비스 던전 나가기 아이콘을 확인해 클릭합니다.
  - `던전에서 퇴장하시겠습니까?` 확인창과 `나가기` 버튼을 함께 확인한 뒤 나갑니다.
  - 던전 밖 HUD 복귀를 확인한 뒤 어비스를 처음부터 다시 시작합니다.
  - 퇴장 확인이 실패하면 제한 재시도 후 화면을 저장하고 구매/부활 입력 없이 안전 정지합니다.

- 어비스 장면 넘기기
  - 현재 실제 화면 기준 우상단 ROI로 좁혔습니다.
  - `장면 넘기기` OCR + 기존 템플릿을 함께 사용합니다.
  - 기존 2프레임 연속 확인 후 클릭 규칙은 유지합니다.
  - `대화 넘기기`는 추가하지 않았습니다.

## 유지 사항

- V0.1.61의 전투→클리어→결과 상태머신과 2프레임 결과 확인 유지
- 회복 물약 부족 팝업 ESC 처리 유지
- 일반 던전 현재 위치 시작 방식 변경 없음
- 페카 심층 이동 로직 변경 없음
- 낚시, F10 정지, UI, 기존 결과 버튼 판정 변경 없음
