# Mabi Auto V0.1.66

V0.1.65를 기준으로 두 번째 실제 녹화에서 확인된 부분을 추가 보강한 버전입니다.

## 변경 사항

- V0.1.65 사망 보조 인식 앞에 남아 있던 OCR 선필터를 수정했습니다.
  - 이제 OCR이 `행동불능`을 놓쳐도 실제 화면의 빨간 `행동불능` + 주황색 `여기서 부활` 시각 신호가 동시에 맞으면 사망 후보가 정상적으로 2/2 확인으로 들어갑니다.
- 사망 2/2 후 5분 대기는 그대로 유지합니다.
- 5분 후에는 **새 화면 2장**에서 사망 상태가 계속 유지되는지 다시 확인합니다.
  - 2/2 유지: 기존 안전 퇴장
  - 한 번이라도 사망 상태가 풀렸거나 다른 화면으로 바뀜: 퇴장 취소 후 현재 진행 계속
- 어비스 `장면 넘기기`는 배경 변화에 민감한 기존 이미지 대신, 실제 영상에서 공통으로 확인된 **긴 흰색 둥근 버튼 테두리**를 감지합니다.
- 장면 넘기기는 기존처럼 별도 프레임 2/2 확인 후에만 클릭합니다.
- 사망 화면이 확인되면 장면 넘기기보다 사망 처리가 우선합니다.

## 유지 사항

- 다시 하기 커서 검증 기준 변경 없음
- V0.1.64 클리어 후보 로그 단순화 유지
- 텔레그램 명령어/약어 변경 없음
- 공용 입력 잠금 유지
- 부활/깃털/구매 입력 없음
- 클리어 → 결과 → 다시 하기 상태머신 유지
- 회복 물약 ESC 처리 유지
- 일반 던전, 페카 심층, 낚시, F10, UI 변경 없음
