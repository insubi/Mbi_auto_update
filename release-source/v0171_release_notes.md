V0.1.70 기반 어비스 퇴장 로직 수정입니다.

- 사망 감지, 사망 확인 카운트, 5분 퇴장 예약, 관련 로그/설정 제거
- 판마다 단일 10분 제한 사용
- 타임아웃 및 퇴장 입력 직전에 클리어/결과 화면 우선 확인
- 실제 퇴장 입력 이후에만 퇴장 상태 표시
- 클리어 및 다음 판 진입 시 퇴장 상태와 알림 예약 초기화
- 기존 정상 클리어, 전리품, 다시 하기 처리 유지
- /item, /itemreset 기능 유지
