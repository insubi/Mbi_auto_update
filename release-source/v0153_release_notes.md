V0.1.53 - 어비스 결과 다시 하기 시각 판별 보강

V0.1.52에서도 결과 화면의 작은 흰색 "다시 하기" 글자를 OCR이 놓쳐 정지하던 문제를 보강했습니다.

- OCR "다시 하기" 인식은 그대로 우선 사용
- OCR 실패 시 800×1000 결과 화면 하단의 초록 버튼 3개를 위치/색상으로 확인
- 사용자 캡처 기준 버튼 위치:
  - 나가기 영역: x=160~340
  - 다시 하기 영역: x=310~490
  - 다른 던전 가기 영역: x=460~640
- 세 영역 모두 충분한 초록색 채움이 있을 때만 결과 화면으로 인정
- 2프레임 연속 확인 후 가운데 다시 하기 영역 중심만 클릭
- 나가기 / 다른 던전 가기는 절대 클릭 후보로 사용하지 않음
- 다시 하기 후 결과 화면 이탈 판별도 OCR+시각 fallback을 함께 사용
- 일반 던전, 페카 심층, 어비스 전투/클리어, 낚시, F10, UI/미리보기 등 다른 기능은 변경하지 않음
