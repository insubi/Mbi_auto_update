V0.1.59 - 어비스 상태머신 명확화

V0.1.58 회귀 테스트를 안전장치로 두고, 기존 어비스 판별/좌표/임계값을 변경하지 않은 채
실제 진행 상태를 명시적으로 관리하도록 보강했습니다.

상태 흐름:
- CombatClearWait: 전투 종료/클리어 화면 대기
- ClearConfirmed: 기존 클리어 타이틀 + 터치 문구 동시 확인
- TouchReady: 터치 위치가 기존 판별로 확정됨
- TouchClicked: 클리어 화면 터치 입력 완료
- ResultConfirmed: 실제 결과 화면 확인
- RetryClicked: 가운데 다시 하기 클릭 완료
- Reentering: 결과 화면 이탈/재입장 확인 중
- CombatClearWait: 기존 기준(결과 화면 3회 연속 이탈 + 입장/필드 화면 아님)으로 복귀

안전장치:
- 허용되지 않은 상태 전이는 즉시 차단
- 클리어 화면 터치는 TouchReady 상태에서만 허용
- 다시 하기는 ResultConfirmed 상태에서만 허용
- 다시 하기 후 전환 확인은 Reentering 상태에서만 허용
- 결과 화면이 확인되지 않으면 기존처럼 다음 단계로 넘어가지 않음
- 전체 사이클 재시작 시 상태를 Unknown으로 초기화
- 오류 메시지에 현재 어비스 상태 추가

변경하지 않음:
- V0.1.55 결과 화면 OCR/초록 버튼 판별 및 ROI
- V0.1.54 클리어→결과 화면 확인 규칙
- 클릭 좌표 및 인식 임계값
- 일반 던전 / 페카 심층 / 낚시 / F10 / UI
- V0.1.56 진단 기능
- V0.1.57~58 자동업데이트 구조

V0.1.59은 새 전투 인식 target을 추가하지 않습니다.
현재 production에는 전투 전용 target이 없으므로, 다시 하기 후 CombatClearWait 복귀 판정은
V0.1.58에서 이미 사용하던 조건을 그대로 상태 전이 근거로 사용합니다.
