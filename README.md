# Mbi_auto_update

MABI AUTO update repository.

Current release: v29

The app checks GitHub Releases for newer versions. Release packages should be attached as ZIP assets.

Recommended package names:
- MabiAuto_v30.zip
- MabiAuto_v31.zip
- MabiAuto_v32.zip

CombinedFishingDungeon_*.zip packages are also supported.
