생활 → 옷감 가공 이미지 준비

이 작업 버전에는 사용자가 다시 제공할 단계 이미지가 아직 없습니다.
profile.json의 Calibrated=false이므로 생활 시작은 차단됩니다.
기존 낚시 / 던전 / 어비스는 이 준비 검사와 무관하게 사용할 수 있습니다.

게임 창 클라이언트 800×1000 원본 캡처를 사용합니다.
배경·캐릭터 외형·아이템 보유 숫자는 템플릿에서 제외합니다.
필요하면 PNG 알파 마스크로 변하는 부분을 제외합니다.
아이템 숫자 OCR 영역은 아이콘 위치에 상대적으로 지정합니다.
황금 양털의 이름 전체와 +가 표시될 오른쪽 여백을 함께 확인합니다.
황금 양털+ 배제용 + 템플릿도 반드시 등록합니다.

필요한 화면 묶음
1. 기본 필드: 가공 탭 / 캐릭터 아이콘의 고정 테두리 / 가방 / 고정 HUD
2. 가공 메뉴: 비활성 / 파란색 활성 / 옷감 가공 / 설비로 이동 / 옷감 아이템 / 가공하러 가기
3. 대기열: 추가 버튼 / 빈 7칸 / 7번 옷감 있음 / 7번 100% / 모두 받기 / 초록색 확인
   슬롯 순서: 위 왼쪽부터 1,2,3,4 / 아래 왼쪽부터 5,6,7
4. 재료 부족 문구 / 흰색 X / 회색 X / 가방 우측 상단 X
5. 생활 스킬 / 양털 깎기 / 양 / 가까운 위치 찾기
6. 채집 중 초록 게이지가 변하는 연속 캡처 4장 이상 또는 짧은 동영상
7. 가방 아이템 탭: 비활성 / 주황색 활성 / 돋보기 / 검색 입력창 / 적용하기
8. 황금 양털과 황금 양털+가 함께 보이는 결과 / 구하는 방법 / 그 안의 양털 깎기
9. 일반 양털 아이콘과 보유 수량이 함께 보이는 가방 화면

활성 상태는 이미지와 색상을 함께 확인합니다.
7번 진행률은 가공 HUD 기준으로 7번 영역에서만 읽습니다.
1~6번 완료율은 수령 조건에 사용하지 않습니다.
목표 수량: 1~9999, 기본값 1000, 생활 설정에 자동 저장.
검색은 Ctrl+A → 한글 텍스트 붙여넣기 → Enter → 적용하기입니다.
숫자가 판독되지 않거나 황금 양털의 정확한 이름을 검증하지 못하면 진행하지 않습니다.

이미지를 반영한 뒤 프로필 검증과 실제 화면 인식 확인이 추가로 필요합니다.
Windows 빌드 성공은 게임 내 동작 성공을 의미하지 않습니다.
