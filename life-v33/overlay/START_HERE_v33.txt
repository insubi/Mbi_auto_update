MABI AUTO v33 생활 기능 작업판

생활 탭에 옷감 가공과 양털 목표 수량(1~9999, 기본 1000)을 추가했습니다.
F9 시작 / F10 정지 / F8 준비 상태 확인.
기존 낚시·던전·어비스 엔진은 유지합니다.

현재 생활 단계 이미지가 아직 제공되지 않아 생활 시작이 차단됩니다.
FishingAutomation/life/templates/README.txt의 화면이 필요합니다.
가공↔일반 양털 채집 흐름과 판정 코드는 추가했지만 실제 게임 GUI는 검증하지 않았습니다.
황금 양털은 자동채집 진입용이며 목표 수량은 일반 양털입니다.

이 작업판의 Windows Lite 빌드 결과는 GitHub Actions에서 확인합니다.
빌드와 규칙 검사 결과를 게임 인식·클릭 검증과 구분하세요.
